# CascadeAuth (RouteOTP)

> Self-hosted engine for multi-channel OTP verification and cost optimization (Telegram -> Flash-call -> SMS).

## Architecture Overview
- **Backend:** NestJS, TypeScript, Modular Monolith
- **State & Queues:** Redis, BullMQ
- **Database:** PostgreSQL, Prisma ORM
- **Dashboard & Sandbox:** Next.js (App Router), Tailwind CSS
- **Infrastructure:** Docker Compose
